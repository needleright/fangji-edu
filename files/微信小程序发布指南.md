## 二、在开发者工具中上传（手动，最可靠）

> 微信小程序没有 APK/IPA 安装包。「打包」= 上传代码到微信公众平台 → 审核 → 发布，用户微信内即用。

1. 打开**微信开发者工具**，关闭当前那个空白新项目（或 项目 → 查看所有项目 → 导入项目）。
2. 点「导入项目」，**目录选择**：
   ```
   /Users/one/Documents/项目/中医方剂小程序/miniprogram
   ```
   AppID 会自动识别为 `wxe37cedcc2a2579f1`，无需手填。
3. 工具自动编译，左侧模拟器即可看到完整功能（首页、学习、测试、抽题、错题本、我的）。
4. 点顶部工具栏 **「上传」** → 版本号 `1.0.0` → 备注「经方六经辨证训练小程序首版」→ 确定。
5. 上传成功后，去 [mp.weixin.qq.com](https://mp.weixin.qq.com) → **管理 → 版本管理**：
   - 把刚上传的「开发版」点 **「设为体验版」**（生成二维码，可发同事试）
   - 或点 **「提交审核」** 走正式发布

## 三、提交审核前，公众平台后台必做两项

代码层面不用动，但后台必须配置，否则审核会被打回：

1. **服务类目**（关键，决定要不要医疗资质）
   - 选 `教育 - 在线教育` 或 `工具 - 信息查询`（**不要**选「医疗健康」，否则需《医疗机构执业许可证》）
   - 功能描述写清楚："中医经方学习 / 备考训练工具，仅供学习，不提供任何诊疗建议"
2. **隐私保护指引**
   - 本程序无 `wx.login`、不取手机号/位置，填"不收集用户信息"即可

## 七、自动上传（CLI）的已知坑（备查）

如需用命令行上传，本机环境有两个坑：

1. **NODE_OPTIONS 冲突**：本机注入了 `--use-system-ca`，微信工具的 node 会拒绝。运行 CLI 前需清空：
   ```bash
   env -u NODE_OPTIONS /Applications/wechatwebdevtools.app/Contents/MacOS/cli \
     -u 1.0.0@/Users/one/Documents/项目/中医方剂小程序/miniprogram \
     --upload-desc "经方六经辨证训练小程序 v1.0.0"
   ```
2. **服务端口需开启并重启**：CLI 调用要求开发者工具「设置 → 安全设置 → 服务端口」开启，且**重启工具后才生效**。否则报 `wait IDE port timeout`。
   — 鉴于重启可能要求重新登录，日常上传**优先用手动按钮**（不走端口，更稳）。
