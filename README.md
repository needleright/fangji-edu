# 经方六经辨证训练小程序

依据 `files/PRD_经方六经辨证训练小程序.md` 开发的微信小程序，覆盖 PRD 的 Phase 1 + Phase 2 全部功能。

## 目录结构

```
├── miniprogram/                 # 微信小程序源码（用微信开发者工具打开此目录）
│   ├── app.json / app.js / app.wxss
│   ├── project.config.json
│   ├── data/formulas.js         # 100 首经方题库（含 300 条口语化症状变式）
│   ├── utils/store.js           # 学习记录 / 错题本 / 收藏 / 统计（本地存储）
│   ├── utils/quiz.js            # 出题引擎（干扰项同经优先）
│   └── pages/
│       ├── index/               # 首页（四大入口 + 进度概览）
│       ├── practice/            # 学习模式 & 随机抽题（3D 翻卡）
│       ├── test/                # 测试模式（选六经 → 选方剂 → 报告）
│       ├── wrongbook/           # 错题本（按错误频次加权排序）
│       ├── list/                # 方剂总览（搜索/筛选）
│       ├── detail/              # 方剂详情（组成/病机/变式/鉴别方跳转）
│       └── profile/             # 我的（六经掌握度雷达图 + 设置）
├── preview/index.html           # 网页版效果预览（无需开发者工具，浏览器直接打开）
├── files/经方数据_100首_已填充.xlsx  # 按录入模板格式回填的完整数据（可人工校对后回灌）
└── data-src/part1~4.json        # 题库源数据（JSON，修改后可重新合并）
```

## 如何运行

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」→ 选择 `miniprogram/` 目录 → AppID 选「测试号」即可预览
3. 有自己的小程序 AppID 时，替换 `project.config.json` 中的 `appid` 后可真机预览/上传发布

## 功能对照 PRD

| PRD 模块 | 实现情况 |
|---|---|
| 5.1 学习模式 | ✅ 翻卡（标准症状+变式随机出题）、六经/难度/出处筛选、已掌握/模糊/不会标记、鉴别方跳转、收藏 |
| 5.2 测试模式 | ✅ 两步作答（多选六经→四选一方剂）、即时判分解析、正确率与薄弱六经分布报告 |
| 5.3 随机抽题 | ✅ 全部/未掌握/收藏/错题组合抽题、连续刷题计次 |
| 5.4 错题本 | ✅ 测试答错+学习标记自动入本、错误频次加权排序、连对 N 次自动移出（N 可在“我的”中设置 2/3/5） |
| 我的 | ✅ 六经掌握度雷达图、进度统计、收藏列表、重置数据 |
| 4.x 数据结构 | ✅ 与 PRD 字段一一对应（症状变式随包内置，均视为已审核 approved） |

## 判分规则（对应 PRD 开放问题 2 的默认决策）

六经（多选，需与答案完全一致）与方剂**两者全对**才计为答对；解析中会分别提示六经/方剂哪一步出错。如需改为部分得分，改 `pages/test/test.js` 中 `pickName` 的 `ok` 逻辑即可。

## 数据维护

- 修改题库：编辑 `data-src/part*.json`（或 Excel 校对后转 JSON），再重新生成 `miniprogram/data/formulas.js`（格式：`module.exports = [...]`）
- `files/经方数据_100首_已填充.xlsx` 为完整数据的 Excel 版本，格式与「经方数据录入模板」一致，便于中医专业人士逐条校对
- **重要**：药物剂量与症状描述由 AI 生成，用于正式发布前建议由专业医师完成一轮内容审核（对应 PRD 第七节的人工审核门禁）

## 后续可扩展（PRD Phase 3 / 后端化）

- 当前学习数据存于本地（`wx.setStorageSync`），迁移微信云开发时只需替换 `utils/store.js` 的读写实现，页面无需改动
- 内容管理后台（录入/AI 生成变式/审核队列）建议按 PRD 做成 PC 网页端，题库改为云数据库下发

## 合规提示

产品定位为中医知识学习训练工具，不提供面向真实患者的诊断/开方建议。
